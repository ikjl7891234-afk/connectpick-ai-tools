# Security and installation policy

- This repository contains documentation only, not executable integrations.
- Never commit API keys, access tokens, session cookies, passwords, patient records, or private client files.
- Review third-party repository licenses, dependencies, installation scripts, permissions, and outbound network calls before use.
- Prefer least privilege and read-only research; request approval before account access or writes.
- Use a separate test environment; review diffs and maintain rollback instructions.
- GitHub repository visibility is PUBLIC at initial inspection. Consider switching to PRIVATE before storing any internal project plans.
